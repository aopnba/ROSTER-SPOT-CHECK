# ROSTER SPOT CHECK

A basketball roster guessing game from ALL NBA. Ten players per round, 10 points per correct answer, and basketball markers for the current answer streak.

A standalone static HTML/CSS/JavaScript game with a 96-player pool and local photos and team logos. Uses the supplied Cooper Black, DS-Digital and Superstar M54 fonts. Font license files are included in assets/.

Run locally: `python3 -m http.server 8093 --bind 127.0.0.1`

Play: https://aopnba.github.io/ROSTER-SPOT-CHECK/
